## Sobre o Projeto

O **dIAgnostic** tem como objetivo criar um aplicativo que facilite o acesso às informações relacionadas à saúde do usuário.

### Benefícios:
- Maior praticidade para consultar resultados de exames
- Informações sobre precauções
- Auxílio na leitura de exames

Este aplicativo não tem a intenção de medicar ou diagnosticar doenças, mas sim alertar o usuário sobre possíveis condições e fornecer informações rápidas sobre o que pode ser observado nos exames.
